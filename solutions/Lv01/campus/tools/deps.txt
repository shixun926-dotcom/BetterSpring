# Lv01 · spring-boot-starter-web 3.5.16 的精确运行时依赖闭包
# ------------------------------------------------------------
# 相对 ~/.m2/repository 的路径，每行一个。
#
# 为什么必须"精确"而不是"把仓库里的 jar 全丢进去"？
#   Spring Boot 的自动配置是按 classpath 上"有什么"来决定"配什么"的。
#   把 spring-boot-starter-jdbc / HikariCP / mysql-connector-j 一起放进去，
#   DataSourceAutoConfiguration 就会生效并索要数据库 url，
#   于是 Lv01 直接启动失败 —— 详见 docs/levels/Lv01-SpringBoot启动.md 附录 B · Lv01-P01。
#
# 这份清单就是 Maven 平时替你算出来的东西。
