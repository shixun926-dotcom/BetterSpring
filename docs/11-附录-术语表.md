## 1. 使用方式

三种用法：

1. **卡住时查**：在 [§3 索引](#3-速查索引) 找到术语 → 看一句话定义 → 跳到"首次出现关卡"的 §7 读完整原理。
2. **复习时自测**：遮住定义，只看术语，能否说出它"解决了什么问题"。
3. **写文档时对齐**：新增内容里出现的术语，若表中没有，**必须补一行**。

⚠️ 本表**不是**知识来源。只看本表 = 又回到了"知识目录"。本表只负责**定位**。

## 4. 易混淆术语对照

📌 这些是最容易被混为一谈的概念，**必须能说清区别**。

| 术语对 | 区别要点 | 相关关卡 |
| --- | --- | --- |
| IOC vs DI | IOC 是"谁来创建对象"（容器）；DI 是"依赖怎么进去"（注入） | Lv05 / Lv06 |
| Bean vs 普通对象 | Bean 是被 Spring 容器创建并管理的对象 | Lv05 / Lv06 |
| `@Component` vs `@Service` vs `@Repository` vs `@Controller` | 语义区分，本质都是 Bean 标记；`@Service`/`@Repository` 语义更明确 | Lv06 |
| `@Controller` vs `@RestController` | `@RestController` = `@Controller` + `@ResponseBody`，直接返回数据 | Lv02 / Lv06 |
| `@PathVariable` vs `@RequestParam` | 前者取自路径 `/students/{id}`，后者取自查询串 `?page=1` | Lv03 |
| `#{}` vs `${}` | `#{}` 预编译防注入；`${}` 直接拼接，有注入风险 | Lv07 |
| Entity vs DTO vs VO | 表映射 / 入参 / 出参，用途不同，不可互换 | Lv16 |
| 认证 vs 授权 | 认证解决"你是谁"；授权解决"你能做什么" | Lv14 / Lv21 |
| 拦截器 vs 过滤器 vs AOP | Filter 在 Servlet 层、Interceptor 在 Spring MVC 层、AOP 在方法层 | Lv17 / Lv18 |
| `@Transactional` 加在 private 方法上 | 不加代理 → **静默失效**，不报错 | Lv12 |
| Session vs JWT | 状态在服务端 vs 状态在客户端 | Lv14 |
| 分页在 SQL 层 vs 内存层 | SQL 层只取一页；内存层已经把全表读出来了 | Lv19 |
| 逻辑删除 vs 物理删除 | 标记 vs 真删；影响唯一索引与查询条件 | Lv09 / 05 附录 B |
