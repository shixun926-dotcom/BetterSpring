## 3. `T-student` · 学生表

### 3.1 参考文档明确给出的字段

📎 原始出处：

> 第 8 关：真正访问 MySQL
> 创建：student 表：id / name / age / gender / class_name

| 字段 | 类型 | 允许空 | 默认 | 说明 | 状态 |
| --- | --- | --- | --- | --- | --- |
| `id` | `INT` | 否 | 自增 | 主键 | 🚧 待建 |
| `name` | `VARCHAR(50)` | 否 | — | 学生姓名 | 🚧 待建 |
| `age` | `INT` | 是 | `NULL` | 年龄 | 🚧 待建 |
| `gender` | `VARCHAR(10)` | 是 | `NULL` | 性别（约定见 §3.3） | 🚧 待建 |
