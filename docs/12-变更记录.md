## 1. 登记规则

### 1.1 什么时候必须登记

| 变更类型 | 必须登记 | 说明 |
| --- | --- | --- |
| 新增章节 / 段落 | ✅ | 类型 `新增` |
| 新增关卡文档 | ✅ | 类型 `新增文档` |
| 新增需求 / 接口 / 表 / 字段 | ✅ | 类型 `新增` |
| 纠正已有结论 | ✅ | 类型 `勘误`，必填"被修正对象、原结论、新结论、原因" |
| 作废整节 / 整档 | ✅ | 类型 `废弃`，必填"取代者" |
| 数据库结构变更 | ✅ | 类型 `DB变更`，同时登记到 [05 §8](05-数据库设计.md) |
| 替换技术方案（如 PageHelper ↔ 手写分页） | ✅ | 类型 `选型`，同时更新 [03](03-技术栈与选型.md) 与 [附录 B](README.md) |
| 修正错别字 | ❌ | 只要不改变语义 |
| 更新统计数字（进度、需求计数） | ❌ | 属快照 |

### 1.2 编号规则

- 格式：`CHG-NNN`，三位数字，从 `CHG-001` 开始。
- **只递增、不复用、不回收**。即使某条被作废，编号仍然占用。
- 每条变更同时决定是否需要 `vX.Y.Z` 版本号变化：

| 触发 | 版本变化 |
| --- | --- |
| 新增文档 / 新增关卡 / 新增需求 | `v0.1.0 → v0.2.0`（次版本 +1） |
| 勘误、废弃、选型替换 | `v0.2.0 → v0.3.0`（次版本 +1，见 [00 §4.3](00-文档使用与维护规范.md)） |
| 仅文字修订、错别字 | 补丁位 +1 |

📌 本项目文档集起步版本为 `v0.1.0`。
